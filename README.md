# حضوربان | HozourBan

سامانه فارسی مدیریت حضور و غیاب و منابع انسانی برای کارخانه و شرکت.

## وضعیت فعلی
نسخه ۰.۱ یک نمونه اولیه فرانت‌اند واکنش‌گراست و شامل داشبورد مدیر، فهرست کارکنان آزمایشی، کیوسک ثبت ورود/خروج با دوربین، تاریخچه تردد و خروجی CSV است.

**مهم:** این نسخه هنوز سامانه عملیاتی نیست. اطلاعات فقط در حافظه محلی مرورگر ذخیره می‌شود؛ احراز هویت واقعی، سرور، پایگاه داده مرکزی، همگام‌سازی چند دستگاه، محاسبه حقوق و تشخیص چهره امن هنوز پیاده‌سازی نشده‌اند. از اطلاعات واقعی کارکنان در این نسخه استفاده نکنید.

## اجرای محلی
نیازمند Node.js نسخه ۱۸ یا جدیدتر:

```bash
npm install
npm run dev
```

برای ساخت نسخه انتشار:

```bash
npm run build
npm run preview
```

برای استفاده از دوربین، برنامه را در مرورگر امن (HTTPS یا localhost) باز کنید و اجازه دسترسی دوربین بدهید.

## حساب‌های نمایشی
- کدهای پرسنلی: ۱۰۰۱ تا ۱۰۰۵
- رمز آزمایشی همه: ۱۲۳۴

این رمزها صرفاً برای نمایش نمونه هستند و امنیت ندارند.
