# راه‌اندازی سرور مرکزی حضوربان

## نکته مهم
ساخت APK به‌تنهایی سرور ایجاد نمی‌کند. برای اتصال واقعی چند گوشی و کیوسک، باید API و PostgreSQL روی یک میزبان دائمی با HTTPS اجرا شوند. هیچ آدرس سرور عمومی برای این پروژه هنوز تنظیم نشده است.

## متغیرهای محیطی سرور
مقادیر زیر را در میزبان تنظیم کنید:
- `DATABASE_URL`: آدرس PostgreSQL
- `JWT_SECRET`: کلید تصادفی محرمانه حداقل ۳۲ کاراکتر
- `NODE_ENV=production`
- `PORT`: میزبان معمولاً خودش مقدار را تعیین می‌کند
- `PGSSL`: بسته به سرویس PostgreSQL، `true` یا `false`
- `CORS_ORIGIN`: آدرس پنل وب در صورت میزبانی وب؛ برای APK اندروید، مبدأهای Capacitor از قبل مجازند.

## فرمان‌های راه‌اندازی
با Node.js 20:
```bash
npm install
npm run migrate
npm run api
```

پس از اجرای migration، فقط یک بار مدیر اولیه و سازمان را بسازید:
```bash
npm run bootstrap
```
مقادیر `BOOTSTRAP_ORG_NAME`، `BOOTSTRAP_BRANCH_NAME`، `BOOTSTRAP_ADMIN_CODE` و `BOOTSTRAP_ADMIN_PASSWORD` را قبل از اجرای bootstrap در محیط قرار دهید. رمز مدیر باید حداقل ۱۴ کاراکتر و محرمانه باشد. شناسه سازمانی که فرمان چاپ می‌کند را برای ورود در برنامه نگه دارید.

## اتصال APK
در صفحه ورود حضوربان:
1. آدرس HTTPS سرور را وارد کنید؛ نمونه: `https://attendance.example.com`.
2. شناسه سازمان چاپ‌شده در مرحله bootstrap را وارد کنید.
3. کد پرسنلی و رمز مدیر را وارد کنید.
4. «اتصال و ورود» را بزنید.

## وضعیت امکانات متصل‌شده
- ورود امن مبتنی بر JWT و نقش‌ها
- فهرست کارکنان و افزودن کارمند
- ثبت رویدادهای ورود، خروج و استراحت با زمان سرور
- مشاهده گزارش تردد و خروجی CSV
- ثبت و بررسی درخواست مرخصی
- اتصال چند دستگاه به یک پایگاه داده مرکزی، پس از میزبانی API

## مواردی که هنوز برای بهره‌برداری کامل لازم‌اند
- میزبانی دائمی API و PostgreSQL، دامنه و TLS و پشتیبان‌گیری زمان‌بندی‌شده
- آپلود امن عکس و سیاست دسترسی/حذف عکس‌ها
- تعریف شیفت‌ها، تقویم تعطیلات، محاسبه تأخیر، اضافه‌کاری و کسری کار
- اصلاح تردد با گردش تأیید و گزارش حقوق و دستمزد
- مدیریت شعب و دستگاه‌ها، ثبت دستگاه و همگام‌سازی آفلاین
- آزمون امنیتی، مانیتورینگ و بازیابی نسخه پشتیبان

تا قبل از انجام موارد بالا از این سامانه برای تصمیم قطعی حقوق و دستمزد یا داده‌های حساس کارکنان استفاده نکنید. تشخیص چهره یا زیست‌سنجی نیز در این نسخه فعال نیست.
